# Локальные шрифты

Посетители сайта получают все выбранные шрифты только с домена сайта.
Запросов браузера к `fonts.googleapis.com` и `fonts.gstatic.com` нет.

В дистрибутив входят ровно два семейства — ими набран сайт по умолчанию:

- **Noto Sans** — основной текст, веса 400, 600 и 700;
- **Noto Serif** — заголовки, веса 400, 600 и 700.

Больше сюда ничего добавлять не нужно: каждое семейство весит около 90 КБ в
репозитории и не даёт ничего, пока не выбрано в админке. Всё остальное
скачивается на сервер по факту выбора (см. ниже).

Пара обновляется воспроизводимой командой:

```bash
npm run sync:fonts
npm run check:fonts
```

Остальной каталог Google Fonts не скачивается заранее. При сохранении дизайна
`LocalGoogleFonts` загружает только семейства, реально выбранные для текста и
заголовков, проверяет WOFF2 и сохраняет их в
`public/uploads/public/google-fonts/<slug>/`. Последующие страницы подключают
локальный `font.css`; Google участвует только в одноразовом серверном импорте.

Для каждого импортируемого семейства обязательны подмножества
`cyrillic-ext`, `cyrillic` и `latin`. `cyrillic-ext` содержит узбекские
**Ғғ, Ққ, Ҳҳ**, а **Ўў** входит в обычное кириллическое подмножество. Если
семейство или заявленный вес не содержит этих глифов, импорт отклоняется.

Шрифты Google Fonts распространяются их авторами преимущественно по лицензии
SIL Open Font License 1.1; при обновлении каталога следует сохранять условия
лицензии конкретного семейства.
